## 4. 기술 메모
- 파이프라인: `prototypes/episode.py`(꼭지 렌더), `render_episode.py`, `episodes/ep02/build_episode.py`(대본·좌석·화면 설정) → `run_segments.sh 1 2 3 4` → 합치기 → 미리보기 → 업로드
- 새 기능: `cam_id`(바뀌면 하드 컷), `push: false`(느린 푸시 끔), 월드 폭 4700, `k_screen`(K+설명 화면만)
- 업로드: `PYTHONPATH=src python -m korea_decoded upload 영상 --title … --description 파일 --tags … --privacy private --publish-at 시각 --thumbnail …`. 공개 상태 변경은 `videos.update`(status 전체를 덮어쓰므로 embeddable·publicStatsViewable 다시 지정)
- 사진: Openverse + Flickr(CC)만 사용 가능. 유튜브·Pexels·Pixabay·Unsplash는 컨테이너에서 막힘, 위키미디어는 속도 제한
- 환경 주의: 백그라운드 렌더가 세션 재시작 때 죽을 수 있음(완성 파일 확인), `pkill -f`는 셸을 죽임
- 렌더·음성 파일은 git에 올리지 않음(`.gitignore`). 대본·스크립트·문서만 커밋
