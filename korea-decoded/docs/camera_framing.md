# 화면 구도 규칙 (운영자 확정, EP.2 작업 중 정리 2026-10-01)

새 에피소드·소개 영상·쇼츠의 화면(카메라·좌석·설명 화면)을 짤 때 **먼저 이 문서를 읽고 따른다.** 코드: `prototypes/episode.py`(샷 종류와 월드 크기), 에피소드별 `episodes/epNN/build_episode.py`(좌석·카메라·화면 배치).

## 1. 좌석 (장면 x 좌표, 0~1920이 기본 화면)
| 캐릭터 | x | 이유 |
|---|---|---|
| Dr. Kangfree (패널) | **−350** | 단독 샷에서 가운데에 오고 이웃 얼굴이 안 걸리게 |
| Master K (앵커) | **650** | 설명 화면 샷의 기준점 |
| Chef Clamsay (게스트) | **2080** | K와 멀리 떨어져 어설프게 투샷에 안 잡히게 |
- 이웃 좌석과 **약 1000px 이상** 간격. 클로즈업(zoom 1.3~1.35)은 좌우 약 ±740px를 보여 주므로, 이보다 가까우면 옆 사람 얼굴이 반쪽으로 걸린다
- 스튜디오 월드 폭 `WORLD_W = 4100` (좌석이 멀어져도 카메라가 월드 끝에 닿아 화면이 한쪽으로 쏠리지 않게)
- **모든 꼭지에서 같은 좌석**을 쓴다 (꼭지가 바뀔 때 인물이 튀지 않게). 게스트가 없는 꼭지는 그 자리를 비워 둔다
- 호스트 두 명끼리 어깨가 겹치지 않을 것 (어깨폭 약 500px, 최소 간격 520px). 옛 소개 릴스는 330/900/1560 좌석이었음(그 영상 전용)

## 2. 샷 종류와 규칙
- **단독 샷(말하는 사람):** 말하는 사람이 **정확히 화면 가운데**. 옆 사람 얼굴이나 어깨 조각이 보이면 안 됨. 카메라 `cam: [그 사람 x, 470, 1.30~1.35]`, ease 0.12
- **마스터 K + 설명 화면 (`k_screen`):** K는 왼쪽, 설명 화면은 오른쪽(960×540 상자, 위치 (880,210)). 카메라 zoom 1.5, 중심 `K + 350`. **K와 화면만** 나온다. 캉프리·셰프는 화면 밖 (보이면 안 됨)
- **설명 화면은 K 줄에만:** 사진·숫자 카드는 마스터 K가 설명하는 줄에만 붙인다. 캉프리·셰프 줄에 걸려 있으면 가장 가까운 K 줄로 옮긴다 (그 인물이 안 보이는 화면을 피하려고)
- **세그먼트 첫 줄:** 말하는 사람이 호스트면 두 호스트 카메라(중심 `(캉프리+K)/2`, zoom 1.22)에서 시작. **셰프가 먼저 말하면 셰프 카메라**로 시작 (두 호스트 샷에서 셰프가 안 보이는 어색함 방지)
- 전체 출연진이 한꺼번에 나오는 오프닝 샷은 쓰지 않는다. 처음엔 K와 캉프리, 게스트는 따로 떨어져 앉아 있다가 카메라가 돌아가 잡는다
- 말하는 줄마다 카메라가 말하는 사람에게 돌아가고 크기를 조금씩 바꾼다 (줄 번호 3의 배수는 zoom +0.06)
- 화면 양옆에 **얼굴이 반쪽만 보이거나 옷 조각이 삐져나오면 안 됨.** 오른쪽 가장자리 확인: 설명 화면 샷의 시야 오른쪽 끝(`K+990`)보다 셰프 왼쪽 어깨(`셰프 x − 260`)가 더 바깥이어야 함

## 3. 설명 화면(사진·카드) 규칙
- 사진은 **CC0/CC BY만**. 화면 아래에 `Photo: 작가 (라이선스)` 크레딧을 자동 표기하고 영상 설명란에도 적는다 (`assets/stock/epNN/credits.json`)
- AI로 그린 그림은 크레딧에 `AI-generated illustration`
- 숫자 카드는 작은 상자(690px)에서도 읽히게 글씨 배율 최소 0.78 (`episode.py card_image`)
- 한 줄 안에서 화면 두 장이 넘어가려면 `screen: [a, b]`, `screen_split: [0.45]`

## 4. 확인 순서 (렌더 전)
1. `build_episode.py`에서 좌석·샷을 만들고, **앞 6줄만 시험 렌더**한다 (단독 샷, K+화면 샷, 셰프 샷이 모두 들어가게)
2. 말하는 사람이 바뀌는 지점마다 프레임을 뽑아 한 장으로 모아 본다 (가운데 정렬, 옆 사람 노출, 화면 가장자리 조각, 설명 화면 글씨)
3. 이상 없을 때만 전체 렌더 (꼭지별 병렬: `./run_segments.sh 1 2 3 4`)

## 6. 이름표 (name chips)
- 책상의 노란 이름표는 카메라가 확대된 샷에서 화면 아래로 밀려 하단 토픽 자막 바 뒤에 숨는다. **`name_chips: true`**를 쓰면 이름표를 책상에서 빼고, 하단 바 **바로 위(y 878~922)에** 화면에 보이는 인물 아래마다 노란 이름 칩으로 그린다 (EP.2부터 기본)
- 새 에피소드의 세그먼트에는 항상 `"name_chips": true`를 넣는다 (2026-10-01 운영자 지적: "토픽 칸이 이름표를 가리네")
