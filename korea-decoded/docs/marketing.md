# 마케팅 운영 체크리스트

성장 공식: **포장(제목·썸네일) × 시청 유지 × 꾸준함 × 커뮤니티**. 영상 품질은 두 번째 항목이고, 나머지는 영상 밖에서 챙긴다.

## 규칙

- **꾸준함 우선**: 롱폼 매주 금요일. 못 만들면 날짜와 무관한 여유분 꼭지로 채움. 8~10편 뒤 분석 보고 주 2회 검토
- **언어**: 제목·설명·태그·자막·커뮤니티 글 등 유튜브 설정은 전부 영어 (다른 외국어는 가능, 한국어 금지). 썸네일 그림 속 한글만 필요할 때 예외
- **썸네일**: 요소 3개 이하(캐릭터 얼굴 + 핵심 그림 + 큰 글자 3~4단어) + 🇰🇷 위치 배지로 한국임을 표시. 매 편 2~3안 A/B 테스트(✅ 전화번호 인증 완료). 만들기: `prototypes/thumbnail.py` (캐릭터 리그 또는 `assets/poses/`의 리액션 포즈)
- **레딧**: 대부분 커뮤니티가 자기 홍보를 싫어함 → 링크만 올리지 말고 흥미로운 사실·짧은 클립을 본문으로, 원본 링크는 댓글에. 올리기 전 해당 커뮤니티 규칙(자기 홍보 비율, 영상 링크 허용 여부) 확인. 같은 글을 여러 곳에 동시에 뿌리지 않음
  - 주제별 후보: r/korea (한국 일반), r/Busan · r/seoul (지역), r/kpop (K-pop 꼭지), r/koreatravel (여행), r/Living_in_Korea (생활 정보)
- **댓글**: 고정 댓글로 질문 → 시청자가 준 주제는 다음 편에서 "viewer request"로 소개
- **커뮤니티 탭**: 수요일쯤 다음 주 후보 주제 3개 투표
- **검색용 설명편**: 뉴스는 1~2주면 조회가 끊김. 가끔 "Why do Koreans...?" 형식의 설명편을 끼워 넣어 검색으로 오래 들어오게
- **콜라보**: 한국 사는 영어권 유튜버를 애니메이션 게스트로 출연시키는 협업 (다른 채널이 못 하는 방식)
- **뉴스레터**: 매주 "이번 주 한국 뉴스 요약 + 영상 링크" (Substack/beehiiv). 대본에서 거의 자동 생성 가능. 알고리즘과 무관한 내 시청자
- **나중에**: 다국어 더빙(스페인어·포르투갈어·인도네시아어), 멤버십·굿즈·협찬·제휴 링크. 유료 광고는 시청 유지율 검증 전엔 하지 않음
