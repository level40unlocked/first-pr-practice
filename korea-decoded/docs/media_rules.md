# 자료화면(사진·영상) 사용 규칙 (2026-10-03, 운영자 요청으로 정리)

> 법률 자문이 아님. 웹 검색과 일반 상식 기준. 애매하면 쓰지 않는다.

## 1. 원칙
- **출처 표시만으로는 허락이 되지 않는다.** BBC 등 언론사의 사진·영상은 약관상 개인·비영리 용도 외에는 별도 허락·비용이 필요하다.
- **공정 이용(fair use)은 기본 수단으로 쓰지 않는다.** 해설이 중심이어야 하고, 콘텐츠 ID는 공정 이용을 판단하지 못해 자동으로 클레임이 걸린다. 수익 창출 때 사용권 증명을 요구받을 수 있다.
- **언론사 사진·영상은 쓰지 않는다.** 기사의 숫자·사실은 우리 그래픽(차트·지도·카드)으로 만들고, 화면 하단에 영어로 출처를 적는다. 예: `Source: Seoul Economic Daily, Oct 1, 2026`

## 2. 써도 되는 자료 (우선순위)
| 순위 | 종류 | 조건 |
|---|---|---|
| 1 | **우리가 만든 것**: 애니메이션 차트·지도·카드, AI 일러스트(화면에 "AI-generated illustration" 표기) | 출처 카드에 기사명·날짜 |
| 2 | **CC BY, CC0, 퍼블릭 도메인(PDM)** (Flickr, 위키미디어 커먼즈; Openverse로 검색) | CC BY는 작가·라이선스 표기. **CC BY-SA, NC, ND는 쓰지 않음** |
| 3 | **공공누리 제1유형(KOGL Type 1)**: 한국 공공기관 자료. 상업 이용·변형 가능, 출처만 표기(게시 연도, 기관명, 웹 주소, 작가) | 자료마다 유형 확인. 제2~4유형은 제한이 있어 사용 안 함 |
| 4 | **허락 받은 자료**: 언론사·기관에 메일로 허락 | 허락 메일을 `docs/permissions/`에 보관 |
| 5 | **유료 라이선스** (BBC Motion Gallery, 로이터, AP, 게티, 연합뉴스) | 꼭 필요한 한 장면일 때만 |

## 3. 기록·표기 방법
- 쓰는 이미지마다 `assets/stock/<ep>/credits.json`에 작가, 라이선스, 원본 링크를 기록 (EP.2와 같은 방식)
- 화면: 사진 아래 `Photo: 작가 (CC BY 2.0)` 표기
- 유튜브 설명문 맨 아래 `PHOTO & IMAGE CREDITS` 목록을 영어로 (EP.2 설명문 참고)
