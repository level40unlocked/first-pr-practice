## 0. 한 줄 요약

Zack D. Films의 **구조(파이프라인·훅·업로드 전략)** 를 벤치마킹하되, **비주얼·캐릭터·소재는 독자 브랜드**로. 영어권 대상, 1인 + 자동화 전제, 툴 비용 0원으로 시작.

## 1. Zack D. Films 채널 분석 (교차검증 완료)

### 1-1. 기본 사실
- 본명 Zachary Dziadul, 1992년생, 미국. 2021-06-07 채널 개설.
- 3D 애니메이션(Blender) 쇼츠로 과학·역사·의학 소재. 인물 미출연, 본인 내레이션만.
- 구독 약 2,800만, 총 조회 약 760억 (2026 기준, 소스별 편차 있음).
- 하루 4~5개 쇼츠 업로드. 2026-06 "Patent Pending" 시리즈 시작.

### 1-2. 성공 요인 (기능별 분해)

| 요소 | 내용 |
|---|---|
| 훅 | 첫 1~3초 **비주얼 충격**(바늘이 피부 뚫기, 장기 단면). 텍스트 훅 아님 |
| 감정 엔진 | 혐오+공포+궁금증 = **병적 호기심(morbid curiosity)**. "불쾌한데 못 끊겠다" |
| 소재 | "What would happen if…" 질문형 + 시청자 댓글에서 소재 소싱. 부조리 what-if("지구인 전원 녹여 양초 만들면") → 댓글 밈 |
| 캐릭터 | 대머리·무표정·마네킹 같은 캐릭터. "90년대 초 CGI, 섬뜩한 미소"(TV Tropes). **그 얼굴 자체가 밈 콘텐츠** |
| 캐릭터 기능 | 고어의 완충재 / 실험용 더미(당하는 놈) / 멍청한 캐릭터 vs 정확한 설명의 대비 / 밈 생산 / 립싱크·감정연기 없음 → 제작비 절감 |
| 파이프라인 | Blender + Cascadeur + BlenderKit + After Effects + EmberGen. Flamenco 렌더팜 + 커스텀 Python 자동화 (외주 계약자 포트폴리오 기준) |
| 조직 | 유일한 공개 채용 직군 = **스크립트 라이터** → 병목은 렌더가 아니라 대본 |
| 브랜딩 | 로고를 씬 속 오브젝트(클립보드, 세포 표면)에 삽입 → 도용 방지 + 각인 |
| 성장 과정 | 2021-06 롱폼(Buc-ee's) → 2022-02 쇼츠 전환 → 6번째 쇼츠(타이타닉)에서 첫 반응 → "Toyota's $2.3B Mistake"로 폭발. **초기 훅은 "큰 숫자+브랜드+반전"**, 의학 3D 스타일은 나중에 진화 |

### 1-3. 흔한 오독
- "하루 4~5편"은 성공 원인이 아니라 결과(팀+2,800만 구독 상태). 1인이 따라하면 품질 붕괴.
- 툴체인 정보는 외주 계약자 1인의 기록. "채널 전체 파이프라인"으로 일반화 금지.

### 1-4. 수익 구조
- 애드센스 추정 월 ~15만 달러(서드파티, 편차 2~3배). 28M 구독·수백억 뷰에서 나오는 숫자 → 쇼츠 RPM은 매우 낮음.
- 1인 초기: 쇼츠 = 유입 퍼널. 수익은 롱폼 컴필레이션·스폰서·템플릿 판매(제3자가 Zack 스타일 Blender 파일을 Gumroad에서 판매 중 = 수요 증명).

## 2. 제약 조건 (설계 최상위)

### 2-1. 유튜브 "비진정성 콘텐츠" 정책 (2025-07-15 시행)
- 대량생산·템플릿 반복·AI 내레이션에 인간 맥락 없는 채널 → 수익화 박탈. 합산 47억 뷰/3,500만 구독 채널 16개 영구정지 사례.
- AI 사용 자체는 허용. "독창적 해설·스토리텔링·교육 통찰" 필요.
- **결론: 완전 무인 금지. "판단은 사람, 생산은 기계."**

### 2-2. 법적
- 타인 로고·음성·캐릭터 복제 금지 ("Zack D Films 목소리 AI", "Zack 스타일 생성기"가 이미 존재 = 리스크 사례).
- 이매탈·장승 등 문화재는 특징만 차용, 그대로 스캔 사용 금지.

### 2-3. 아동용(COPPA) 오판
- 3D 캐릭터는 "made for kids" 자동 분류 위험 → 채널·영상 모두 "아동용 아님" 고정, 소재는 성인 호기심.

## 3. 시장 전략

### 3-1. 영어권 1차 시장
- 이유: 비주얼 90%·내레이션 단순 → 영어 장벽 낮음. 시청자 10배, 광고 단가·스폰서 풀 큼.
- 주의: 영문 시장도 Zack 아류는 레드오션(Fiverr $30 서비스, AI 생성기 다수). "영어+3D"만으론 차별화 안 됨.

### 3-2. 차별화 = 포맷 벤치마킹 + 소재·비주얼 독자화
- **K각도**: 한국인이라 미국 크리에이터가 못 하는 소재. 보편 주제(신체·물리·돈) 50% + 한국 각도 50%.
- 경쟁 조사 결과: "K문화 × Zack 포맷 × 영어" 채널은 웹 검색 범위에서 **미발견**. 인접: See U in History(2D 신화, 도깨비·귀신 다룸), Korean Englishman(실사). 단, Zack 본인이 한국 소재 쇼츠를 시작했다는 기록 있음(나무위키 스니펫, 원문 미확인) → 수요 검증 + 1위 사업자 진입 가능성.
- 직접 확인 필요: 유튜브 앱에서 `korean history 3d animation`, `fan death animation`, `korean plastic surgery animation` 등 검색 → 구독 10만+ 채널 수 세기.

### 3-3. 잘 맞는 K소재
- 몸/의학: 성형수술 단면(안면윤곽·쌍꺼풀)
- 부조리 믿음: 선풍기 사망설(fan death)
- 역사 잔혹: 조선 형벌·고문, 궁중 의학, 거북선 내부
- 큰 숫자+브랜드: "삼성이 X억 달러 날린 실수"
- 요괴: 귀신·도깨비·구미호를 3D로
- 일상 what-if: 한국식 나이, 군대, 찜질방, 소주, 김장

### 3-4. 언어·더빙
- 원본 영어. 롱폼은 유튜브 자동 더빙(무료, 2026-02부터 전 크리에이터, 27개 언어, 한↔영 양방향).
- **쇼츠 자동 더빙은 지원 미확인** → 쇼츠 다국어는 파이프라인에서 직접(대본 번역 → 내 목소리 다국어 TTS → 오디오 리먹스) → 언어별 채널.
- 한국어 채널은 부산물로.

| 레버 | 값 |
|---|---|
| 재질 | 한지·펠트 질감(섬유 결), 무광 |

| 전환 | 병풍 접힘 / 먹물 번짐 X-ray (시그니처 샷) |
| 텍스트·로고 | 한글+영어 이중 타이포, 로고는 낙관(도장) 형태로 씬 내 삽입 |

## 5. 캐릭터

### 5-1. 방향 (3안 생성 후 결정 대기)
| 안 | 특징 | 비고 |
|---|---|---|
| A. 병맛 | 이매탈식 턱 없음, 눈 벌어짐, 삐뚤한 입, 통통 | 밈 강함, 유치해질 위험 |
| B. 병맛+약함 | A + 앙상한 팔다리, 처진 어깨, 창백, 숱 없는 머리 | "당하는 놈" 강화 |
| **C. 평범+어긋남 1개 (현재 선호)** | 지하철에서 지나칠 평범한 30대 회사원. 시그니처 = **턱 없음** + 입 살짝 벌어짐. 마르고 어깨 처짐 | K일상 소재와 맞음, 아동용 오판 낮음, 의상이 잘 보임 |

### 5-2. 고정 규칙 (어느 안이든)
- 절대 잘생기거나 멋지지 않음. 귀엽지도 않음 (귀여움 = 긴장감 상실 + 아동용 위험).
- **무반응 연기**: 무슨 일이 일어나도 표정 유지. 표정 셰이프키 3개(멍함·멍한 미소·살짝 걱정)면 끝.
- **립싱크 없음**: 내레이터는 화면 밖. 캐릭터는 말 안 함.
- 몸은 물렁·둥글게(인형이 당하는 것으로 읽히게) 또는 마르고 약하게.
- 이름: **Gobo(고보)** — 채널명 후보 §8 참고.

### 5-3. 렌더링 개념: "종족 + 슬라이더"
- 베이스 메시 1개 + 셰이프키(키·살·눈간격·턱·표정) + 재질 프리셋 + 의상 슬롯 + 모션 프리셋.
- 고정(브랜드): 얼굴 규칙, 셰이더, 연기 규칙, 12fps.
- 변수(시드 랜덤): 키·몸무게·피부톤·머리·성별·액세서리.
- 역할: `hogu`(고정 시드, 매번 같은 Gobo) / `extra`(랜덤 시드).
- 결정적(같은 시드 = 같은 결과) → 생성형 AI의 일관성 문제 없음.
- 초기 구축 ~1주 (베이스 메시 1~2일 또는 외주 $200~500, 셰이프키 0.5~1일, Rigify 0.5일, 의상 6~8벌 1~2일, 스크립트 0.5일). 이후 캐릭터 한계비용 0.
- 동작: Mixamo(무료) 프리셋 20개 + 특수 동작만 Cascadeur.
- 베이스: MPFB/CharMorph로 몸 비율, 얼굴은 직접 조형/외주. 생성형(Tripo/Meshy)은 소품·배경만.

### 5-4. 상황 이해 (예: 김장)
- Claude가 상식으로 아는 것: 50~60대 아줌마, 뽀글 파마/머리수건, 빨간 고무장갑, 팔토시, 앞치마, 몸빼, 양반다리, 파란 비닐, 빨간 다라이, 절인 배추, 양념, 수육, 김치통, 11월 형광등.
- 리포 카탈로그가 알아야 하는 것: 그 의상이 `outfit: "kimjang_ajumma"`로 .blend에 존재하는지.
- 없으면 Claude가 "카탈로그에 없음 → 로컬 제작 필요"로 스펙 명시.
- 세부가 틀리면 한 줄 피드백 → bible에 누적.

## 6. 자동화 시스템

### 6-1. 원칙
**판단은 사람, 생산은 기계.** 완전 무인 단계는 두지 않음(§2-1).

### 6-2. 파이프라인
```
[GitHub Actions – 클라우드, cron]
  소재 수집(댓글·Reddit) → LLM what-if 변환·감정 점수 → 후보 큐
  → (사람: 하루 10분 선정) → 대본 초안(LLM) → (사람: 검수)
  → TTS(내 목소리) → job.json 커밋
        ↓ runs-on: self-hosted
[내 PC – RTX 5050, 셀프호스티드 러너]
  Blender 헤드리스 렌더 → FFmpeg 합성·자막·로고 → YouTube API 업로드
        ↓
[GitHub Actions]
  애널리틱스 수집 → 훅 승률 테이블 → 다음 소재 선정 반영
```

### 6-3. 단계별 자동화 정도
| 단계 | 정도 |
|---|---|
| 소재 수집 | 100% 자동 |
| 소재 선정 | **사람** (정책상 독창성 근거 + 품질 게이트) |
| 대본 | LLM 초안 → 사람 수정. 템플릿: 질문형 첫 문장(3초) → 전개 2~3비트 → 반전 → CTA 없이 컷 |
| 내레이션 | 자동 (내 목소리 클로닝) |
| 비주얼 | 자동 (Blender 템플릿 + Python 조립) |
| 합성·자막·로고 | 자동 |
| 업로드 | 자동 (YouTube API + IG Reels 동시) |
| 분석 | 자동 |

### 6-4. 로컬에서만 해야 하는 것
- Blender 렌더링 (GPU)
- 캐릭터·씬 템플릿 제작 (GUI 작업, 초기 1회)
- 렌더 결과 눈 검수 (로컬 Claude Code는 PNG를 직접 볼 수 있음 → bible 체크리스트 대조 자동화 가능)
- PC 꺼져 있을 때 대안: SheepIt(무료 분산 렌더팜), RunPod/Vast.ai($0.3~0.5/h)

### 6-5. 업로드 전 자동 차단 규칙
- 최근 N편과 씬 조합 중복률 X% 초과 → 보류
- 대본에 사람이 쓴 고유 관점 문장 없음 → 보류
- AI 요소 사용 시 라벨 미체크 → 보류
- 유혈 수위 광고 적합성 등급 초과 → 경고

### 6-6. 리포 구조 (캐릭터 바이블)
```
repo/
├─ CLAUDE.md                  # 세션마다 자동 읽힘. "작업 전 bible/ 읽어라"
├─ bible/
│  ├─ character.md            # 고정 규칙 + 금지사항
│  ├─ outfits.json            # .blend에 존재하는 의상 슬롯 + 어울리는 상황
│  ├─ props.json / motions.json / scenes.json
│  ├─ style.md                # 한지 배경, 오방색, 12fps, 카메라 규칙
│  └─ examples/               # 잘 된 job.json 5~10개
├─ schema/job.schema.json
└─ scripts/validate_job.py    # 존재하지 않는 에셋 지정 시 거부
```

## 7. 툴 스택

### 7-1. Blender vs Unreal
- **Blender 채택.** 채널 본인도 Blender. 인체·의학·오브젝트 클로즈업(SSS·굴절·단면)에 강함. Python 헤드리스 렌더 → 자동화 유리. 8GB VRAM에 적합. 스타일 튜토리얼·템플릿이 전부 Blender 파일.
- Unreal 5.8(2026-06, UE5 마지막)은 대규모 환경 시네마틱에 강하나 8GB VRAM에 빡빡, 프로젝트 수십~수백 GB, 에디터 프로세스 필요. 12~16GB GPU + 도시·재난 소재 비중 커지면 하이브리드 재검토.
- Blender 현재 안정판 5.2(2026-07-14).

### 7-2. RTX 5050 (8GB GDDR7, Blender Open Data ~2,873)
- Cycles + OptiX + 디노이즈, 샘플 64~128. 히어로 샷만 Cycles, 나머지 Eevee.
- 텍스처 2K 이하, Persistent Data, 볼류메트릭 저해상도.
- LLM·TTS·렌더를 동시에 올리지 말 것 → 단계별 순차 로드.

### 7-3. 무료/유료
| 단계 | 무료 (시작 구성) | 유료 (선택) |
|---|---|---|
| 3D | Blender, MPFB/CharMorph, Rigify, Mixamo, Cascadeur 무료티어, BlenderKit 무료분, Poly Haven | Cascadeur 유료, BlenderKit 구독, EmberGen, 캐릭터 외주 $200~500 |
| 음성 | **Chatterbox**(오픈소스, MIT, 5~10초 샘플 복제, v3 25개 언어) | Fish Audio $11/월, ElevenLabs $6~22/월(무료 플랜은 상업 이용 불가) |
| 자막 | NVIDIA Parakeet-TDT 0.6B(단어 타임스탬프, 영어/유럽어, 한국어 미확인 → Whisper 병행) | — |

## 8. 채널 설정 (영어권 대상)

### 8-1. 원칙
채널 국가 = **대한민국(실거주)**. 언어·콘텐츠·초기 시청자로 영어권 타깃. 국가 속이기 = 약관 위반, 실익 없음.

### 8-2. 설정값
| 항목 | 값 |
|---|---|
| 계정 | 전용 구글 계정/브랜드 계정 |
| 채널명·핸들·설명·배너 | 영어만 |
| 기본 언어 | English. 업로드 시 `defaultLanguage`, `defaultAudioLanguage` = `en` |
| 시청자층 | "아동용 아님" 채널·영상 모두 고정 |
| 카테고리 | Education 또는 Entertainment 고정 |
| 합성 콘텐츠 라벨 | AI 음성·요소 있으면 체크 |
| 댓글 | 허용 + 검토 대기 + 링크 차단 |
| 자동 더빙 | 켬 (롱폼) |
| 업로드 시간 | 미국 동부 저녁 = 한국 아침 7~10시 |

### 8-3. 초기 시딩
- 첫 20~50편이 시청자 국적 결정. **한국 지인·커뮤니티에 공유 금지.** 제목·설명·해시태그 한국어 금지.

### 8-4. 수익화 (YPP, 2026)
- 1단계(팬펀딩): 구독 500 + 90일 공개 업로드 3 + (12개월 3,000시간 또는 90일 쇼츠 300만 뷰)
- 2단계(광고): 구독 1,000 + (12개월 4,000시간 또는 **90일 쇼츠 1,000만 뷰**). 쇼츠·롱폼 합산 안 됨.
- **2027-02-01부터 신규 신청 기준 2배**(8,000시간 / 2,000만 뷰). 그 전 통과가 목표.
- 심사에 비진정성 정책 적용 → 사람 기획 구조 + AI 라벨.

### 8-5. 애드센스·세금
- 한국 주소, PIN 우편 인증. **W-8BEN 제출 → 한미 조세조약 10%** 원천징수(미국 시청자 수익). 미제출 시 전 세계 수익 24%. 3년마다 갱신.
- 지급: SWIFT 가능 계좌 또는 Wise. 한국 세무: 부가세 영세율, 종합소득세. 규모 커지면 세무사.

### 8-6. Google Cloud / API (첫날)
- 프로젝트 생성 → YouTube Data API v3 + Analytics API → OAuth(`youtube.upload`, `youtube`, `yt-analytics.readonly`)
- **API 컴플라이언스 감사 신청** (미검증 앱 업로드 = 강제 비공개, 승인 1~4주)
- 쿼터 10,000/일, 업로드 1,600 → 하루 6편. 초과 시 증설 신청.

### 8-7. 크로스 플랫폼
- TikTok은 가입 지역(SIM·IP)으로 배포 지역 결정 → 한국 계정은 한국 위주. 우회는 약관 위반 → 후순위. **Instagram Reels**(언어 기반) 2순위.

### 8-8. 채널명
- 알고리즘엔 무관, 사람(재인식·댓글 밈·씬 속 로고·구두 추천)엔 영향 큼.
- 구조: 얼굴 없는 채널 → **캐릭터 이름 = 채널명 = 로고** 통합이 가장 강함.
- 피할 것: Official/TV/Shorts/숫자 접미사, 발음 불가, 흔한 단어.
- **후보: Gobo(고보)**
  - 통과: "GO-bo" 단일 발음, 2음절, "-보" 어감(바보·먹보) = 당하는 놈, 4글자 로고, "Poor Gobo" 밈 가능, 영어권 부정 속어 없음.
  - 걸림: 조명 용어(스텐실), 일본어 우엉, **Fraggle Rock 주인공 Gobo**(짐 헨슨 IP, 2022 리부트). 단독 검색 시 프래글이 먼저. @gobo 핸들 거의 확실히 선점.
  - 해결: 캐릭터 = Gobo, 채널명 = Gobo + 한 단어. **Poor Gobo**(컨셉 전달) 또는 **Gobossi**(고보씨, 유일성·K 정체성). 대안: Hey Gobo, Gobo Kim.
  - 확정 전 확인: 유튜브·IG·TikTok 핸들, 도메인, USPTO/KIPRIS 상표, 프래글 이미지(주황 털)와 비겹침 유지.
- 변경 비용: 첫 1,000 구독 전엔 낮음, 이후 사실상 고정.

0. **훅 실험 (2~4주, 자동화 안 함)**: "큰 숫자+브랜드" / "what-if 부조리" / "신체·의학" × 각 5편 = 15편. 스타일 고정 금지. 3초 유지율만 확인.

3. **수익 아키텍처**: 상위 쇼츠 → 롱폼 컴필레이션, 스폰서 킷, 템플릿 판매. 첫 채용은 대본 작가.
